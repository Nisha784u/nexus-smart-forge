# NexusFlow AI

Build a complete, production-quality DESKTOP-FIRST SaaS web application called:

NEXUSFLOW

AI-Powered Project Management Platform

Use the attached image ONLY as a visual inspiration/reference for the overall visual language, premium dark aesthetic, color depth, glow, spacing and UI quality.

Do NOT copy the exact layouts, text, branding, or individual components from the image.

==================================================

CORE PRODUCT

==================================================

NexusFlow is NOT a chatbot.

It is a professional project management SaaS platform where AI is deeply integrated into project workflows.

Primary experience:

Projects → Tasks → Kanban → Calendar → Team

AI is an intelligent layer throughout the application.

The product should feel comparable in polish to premium modern SaaS products such as Linear, Height, Notion, or Linear-style productivity tools, while having its own distinctive identity.

DESIGN DIRECTION

==================================================

DO NOT create a generic AI dashboard.

Visual identity:

Premium futuristic dark SaaS.

Primary background:

Very deep navy / near-black.

Surfaces:

Dark navy / charcoal with subtle depth.

Accent colors:

Electric blue

Indigo

Violet

Use gradients carefully.

AI elements can use:

Electric blue → indigo → violet glow.

Text:

Soft white / cool gray.

Borders:

Very subtle blue-gray borders.

Avoid:

- Generic purple dashboard templates

- Excessive glassmorphism

- Excessive neon

- Flat gray UI

- Huge gradients everywhere

- Cartoonish effects

- Excessive rounded cards

- Basic Bootstrap-style layouts

The interface should feel sophisticated, premium and intentional.

==================================================

GLOBAL MOTION SYSTEM

==================================================

Every screen must have polished animations.

Use Framer Motion.

Animation principles:

- Page entrance: fade + subtle upward movement

- Cards: staggered entrance

- Hover: subtle elevation + border glow

- Buttons: smooth scale/brightness transition

- Navigation: sliding active indicator

- Modals: fade + scale

- Dropdowns: fade + vertical movement

- Charts: animated entrance

- Numbers: count-up animation

- Progress bars: animated fill

- Lists: staggered item entrance

Keep animations fast and professional.

Never use excessive bouncing.
